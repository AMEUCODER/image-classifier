One folder per person, named as you want the output folder named. Example:

  Faces/train/Madonna/        30 clear photos of her, varied light and angles
  Faces/train/Elton John/     30 photos
  Faces/train/Ben Afflek/     30 photos

To add someone later: add a new folder here and run  python main.py
To retrain everything from scratch: delete models/faces_trained.yml and
models/faces_labels.json, then run  python main.py

Photos of real people are not included in this project; use your own.
